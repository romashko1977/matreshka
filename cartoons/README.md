# Мини-мультфильмы про Чебу Романовича

Генератор: **Seedance 2.5**.

## Структура

- `characters/` — карточки персонажей (неизменные блоки описаний для промтов)
- `episodes/` — серии: одна папка или файл на серию, сцены с готовыми промтами

## Как собирать промт для сцены

1. Загрузить картинку-референс персонажа (image-to-video / reference), если сцена с ним.
2. Промт в порядке: **кто в кадре** (блоки из карточек) → **что делает** → **камера** → **свет и место** (блок стиля) → **звук и реплики**.
3. Одна сцена = 5–10 секунд, одно главное действие.
4. Реплики писать по-русски в кавычках с указанием говорящего.
5. Не использовать названия известных мультперсонажей, только описание.

## Диалоги

Диалоги — главное в сериале. Автор присылает текст, реплики подгоняются под сцены.

### Правила подгонки
- **Длина:** ~2 слова в секунду. Сцена 10 сек ≈ до 20 слов на всех. Длинный диалог режется на несколько сцен
  (крупный план говорящего → реакция второго → ответ).
- **Не больше двух говорящих в одной сцене.** Остальные реагируют молча.
- **Смешное:** пауза перед панчлайном, реакция лица важнее слов (ухо дёрнулось, моргание, каменное лицо).
- **Важное:** крупный план, тишина вокруг, медленная камера, реплика короткая.
- **Смысл автора не меняется**, правится только ритм и длина. Если реплику пришлось сократить, полный вариант
  остаётся в сценарии для озвучки.

### Формат в промте
В конце промта сцены:
```
Dialogue in Russian, with lip-sync:
<ГЕРОЙ> (<голос, интонация>): "<реплика>"
```

### Голоса (указывать каждый раз одинаково)
| Герой | Голос |
|---|---|
| Чебу Романович | low, husky, calm male voice, slow speech, short phrases |
| Валькирия | gentle, warm female voice, very fast chatter, rising intonation |
| Дирк | lively, high-pitched boy's voice, excited, fast |
| Братья | rough, raspy male voices, street slang manner |

### Если нейросеть плохо озвучивает по-русски
Генерировать сцену без речи (`characters talk, no audio`), а голоса сделать отдельно
(например, ElevenLabs) и наложить в монтаже.
