# Мини-мультфильмы про Чебу Романовича

Генератор: **Seedance 2.5**.

## Структура

- `characters/` — карточки персонажей (неизменные блоки описаний для промтов)
- `episodes/` — серии: одна папка или файл на серию, сцены с готовыми промтами

## Как собирать промт для сцены

1. Загрузить картинку-референс персонажа (image-to-video / reference), если сцена с ним.
2. Промт в порядке: **кто в кадре** (блоки из карточек) → **что делает** → **камера** → **свет и место** (блок стиля) → **звук и реплики**.
3. Одна сцена = 5–10 секунд, одно главное действие.
4. Реплики писать по-русски в кавычках с указанием говорящего.
5. Не использовать названия известных мультперсонажей, только описание.
